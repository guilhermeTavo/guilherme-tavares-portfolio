# Guilherme Tavares — Portfolio

Personal portfolio for **Guilherme Tavares**, a QA Engineer focused on software quality and AI evaluation.

## Positioning

**QA Engineer | AI Quality & Software Testing**

The site puts professional experience first and uses independent QA labs as evidence of depth.

## Featured work

- LLM Quality & Red Teaming Lab
- LLM Localization QA Lab
- Customer Support QA & Bug Triage Lab

## Stack

Static HTML, CSS, and vanilla JavaScript.

The project intentionally avoids framework overhead to keep the portfolio fast, accessible, and easy to deploy on Vercel.

## Run locally

Open `index.html` with a local web server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Import the repository into Vercel as a static site. No build command is required.
